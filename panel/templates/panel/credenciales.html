Cómo obtenerla

  1. En Google Cloud Console crea (o elige) un proyecto con facturación activa.
  2. Habilita la Maps Static API.
  3. Crea una clave de API en «Credenciales» y, si quieres, restríngela a esa API.
  4. Pégala aquí y pulsa «Probar clave».

«Probar clave» usa lo escrito en el campo (o la guardada si lo dejas vacío) sin guardarlo.
